# 落霞剑缘

原创引擎 + 原创内容的中式奇幻 JRPG，机制致敬仙剑奇侠传 98 温柔版的年代感。
人物、剧情、数值、美术全部原创，不含任何原作素材。

## 直接玩

浏览器打开 `index.html` 即可，无需构建、无需服务器、无外部依赖。

| 操作 | 按键 |
| --- | --- |
| 移动 | 方向键 / WASD |
| 交互 · 确认 | 空格 / 回车 |
| 状态栏 | Tab / i |
| 存档菜单 | Esc |
| 音乐开关 | n |

存档菜单里：↑↓ 选择槽位，空格/回车 保存，`l` 读取，`x` 删除。
除手动存档外，行走时每 5 秒自动存档一次，标题界面按 `c` 可继续上次进度。

## 技术要点

- **虚拟分辨率 320×200**，画布 960×600，整数 3 倍放大，像素不糊
- **高清美术层**（`src/art.js`）：异步加载生成式美术资产，未就绪或加载失败时
  自动回退到程序化绘制的像素画，游戏永远不会因缺图白屏
- **零依赖**：纯 HTML + 原生 JS，无框架、无打包、无 npm 包

## 目录

```
index.html          入口（按顺序加载各模块脚本）
assets/             美术资产 + art_manifest.js 清单
src/
  pat.js            程序化瓦片绘制（兜底）
  mgo.js            程序化行走精灵（兜底）
  art.js            高清资产加载与绘制层
  data.js           数值表：角色、敌人、物品、法术、升级曲线
  maps.js           场景地图与瓦片定义
  script.js         事件脚本、对话、商店货单
  engine.js         主循环、输入、碰撞、对话、商店、存档
  battle.js         回合制战斗系统
  main.js           启动流程与自动存档
tools/
  smoke_test.js     Node 冒烟测试（76 项断言 + 2000 次随机模糊）
  verify_maps.js    地图可达性校验
  build_assets.py   生成式美术后处理（抠图、缩放、切帧）
  gen_assets.py     美术资产生成
qa/                 开发期视觉验证截图
```

## 测试

```bash
node tools/smoke_test.js    # 76 项断言 + 2000 次模糊操作
node tools/verify_maps.js   # 地图可达性
```

冒烟测试用 Node 里的浏览器桩驱动真实游戏循环，覆盖标题、行走、碰撞、
对话、商店、战斗、Boss、结局、三槽存档，并做 2000 次随机按键的健壮性模糊测试。

## 重新生成美术

若改了 `assets/raw/` 下的原图，需要重新后处理：

```bash
python3 tools/build_assets.py && node tools/smoke_test.js
```
